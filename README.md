# Portfolio Website

This is a simple and responsive portfolio website built using HTML, CSS, and JavaScript. It is designed to showcase projects, basic information, and contact details in a clean and interactive way.

## Features

* Responsive layout for different screen sizes
* Dark mode toggle
* Typing animation on the homepage
* Smooth scrolling navigation
* Project section with filtering
* Basic contact form validation

## Tech Stack

* HTML
* CSS
* JavaScript

## How to Run

1. Download or clone the repository
2. Open the project folder
3. Run `index.html` in your browser

## Note

You can replace images and project details with your own content to customize the portfolio.
